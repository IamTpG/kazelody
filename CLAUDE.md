# KazeLody

A free, non-profit calm music player set in a pre-rendered 2.5D painted valley (day/night cycle, parallax). Tracks are CC0 / CC-BY only.

## Stack
- Language/runtime: TypeScript 7 (`~7.0.2`), ES modules, Node TODO (no `engines`/`.nvmrc`)
- Frameworks: React 19, Vite 8, Tailwind 4, React Three Fiber 9 + three 0.187
- Data: no database; library is one `tracks.json` in a private Cloudflare R2 bucket
- Package manager: npm
- Other: Vercel (static + Functions in `api/`), `@aws-sdk/client-s3` for R2, oxlint, `node --test`

## Layout
- `api/`: Vercel Functions (`/api/tracks`, `/api/admin/*`); `api/_lib` = helpers, not routes
- `shared/`: DOM-free code used by app, api and tools (track model, license table, library, time)
- `src/audio/`: player core (queue/shuffle, `<audio>` wrapper, sources, media session)
- `src/ui/`: overlay, player, playlist, TimeArc; `src/admin/`: lazy-loaded `/admin` page + its logic
- `src/scene2d/`: the 2.5D parallax scene; `src/scene/`: helpers shared with the scene (mulberry32, wind uniforms)
- `tools/`: CLI tools (local manifest, push to R2, dev sandbox, scene capture); `captures/` is git-ignored
- `design/`: logo work; `public/scenes/valley/`: generated scene images

## Commands
- Install: `npm install`
- Dev: `npm run dev` (app) / `npm run dev:admin` (app + in-memory API + fake R2)
- Typecheck: `npx tsc -b` (no dedicated script; also runs in build)
- Lint: `npm run lint`
- Test (all / single): `npm test` / `node --test path/to/file.test.ts`
- Build: `npm run build`
- Run the full check before proposing a commit: `npm run lint && npm test && npm run build`

## Conventions
- Tests sit next to the code as `*.test.ts` (node:test); non-UI logic goes in `shared/`, `src/audio/` or `src/admin/*.ts` so it stays testable.
- `shared/` must stay DOM-free (used by browser, api and tools).
- Playback time is read from `player.currentTime` in `requestAnimationFrame`, never stored in React state.
- Motion in UI limited to `transform`/`opacity`; respect `prefers-reduced-motion`.
- `src/scene2d/valleyData.ts` is generated by `tools/build-scene-data.mjs`; do not hand-edit.
- Track file names: `Artist__Title__License[__source].ext` (see `docs/music.md`).

## Do not
- Do not open or render painted-valley on a real GPU or in a browser (it froze browsers); capture is CPU-only via `tools/capture-scene.mjs`.
- Do not add runtime 3D geometry, MSAA or post-processing to the scene; the weak-GPU budget is the reason for the 2.5D design.
- Do not put R2 credentials or other secrets in `src/` or `shared/`; they belong in `api/` and `tools/` via env vars.
- Do not read or edit `.env*` files except `.env.example`; keep `.env.example` current.
- Do not add dependencies without asking.
